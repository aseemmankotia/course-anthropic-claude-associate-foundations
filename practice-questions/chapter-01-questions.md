## Chapter 1: Exam Overview and How Claude Products Work — Practice Questions

**Q1.** A candidate is scheduling their CCAO-F exam timing strategy for 60 questions in 120 minutes. To leave buffer time for flagged-question review at the end, what pacing should they target?

A) Exactly 2 minutes per question, using all 120 minutes with no review time
B) Under 2 minutes per question (roughly 1:30–1:45) to bank time for review
C) 3 minutes per question, planning to answer only the easiest 40 questions
D) No pacing plan — answer as fast as possible on every question regardless of difficulty

<details>
<summary>Answer</summary>

**Correct: B**

120 minutes ÷ 60 questions = 2:00/question average; pacing slightly under that average (e.g., 1:30–1:45) creates a review buffer for flagged items near the end.

**Why the others are wrong:**
- Using the full 2:00 average on every question leaves zero time to revisit flagged questions.
- 3 minutes/question only covers 40 questions in 120 minutes, leaving 20 unanswered.
- No pacing plan risks running out of time on later questions and skipping easy points.

> ⚠️ Frequently missed on the exam — read the options carefully.

</details>

**Q2.** A team needs a Claude.ai workspace that keeps reusable context — style guides, reference documents, and prior conversation history — available across multiple future conversations on the same project. Which surface BEST fits this need?

A) Chat
B) Artifacts
C) Projects
D) Research mode

<details>
<summary>Answer</summary>

**Correct: C**

Projects is designed to hold persistent, reusable context (documents, instructions, prior chats) that carries across multiple sessions within that project.

**Why the others are wrong:**
- Chat is a single conversation thread without built-in persistent shared context across sessions.
- Artifacts is for standalone generated outputs (code, documents) rather than ongoing shared project context.
- Research mode is for multi-step research synthesis, not for storing reusable reference material.

</details>

**Q3.** A candidate wants to take the CCAO-F exam remotely from home instead of visiting a physical location. Which option should they select when scheduling through Pearson VUE?

A) OnVUE online proctoring
B) Physical test center appointment
C) Unproctored self-study mode
D) Mail-in paper exam

<details>
<summary>Answer</summary>

**Correct: A**

OnVUE is Pearson VUE's online proctoring option, allowing candidates to test remotely with a live or AI proctor monitoring via webcam.

**Why the others are wrong:**
- A physical test center appointment requires traveling to a Pearson VUE testing location.
- There is no unproctored self-study mode for the certification exam — proctoring is required for a valid score.
- Mail-in paper exams are not a delivery format Pearson VUE offers for this certification.

</details>

**Q4.** A candidate receives a scaled score report showing 695 for the CCAO-F exam. What is the correct interpretation of this result?

A) Passed, because 695 exceeds the minimum scaled score
B) Borderline pass pending manual review by Anthropic
C) Passed, because the passing threshold is 650, not 720
D) Failed, because the scaled score is below the required 720 threshold

<details>
<summary>Answer</summary>

**Correct: D**

The CCAO-F exam uses a 100–1000 scaled score with 720 as the minimum passing score; 695 falls below that threshold, resulting in a fail.

**Why the others are wrong:**
- 695 does not exceed 720, so this does not qualify as a passing score.
- There is no borderline manual review process — the scaled score threshold is the sole pass/fail criterion.
- 650 is not the correct passing threshold; 720 is the documented minimum.

> ⚠️ Frequently missed on the exam — read the options carefully.

</details>

**Q5.** On the CCAO-F exam, what distinguishes a multiple-response question from a multiple-choice question?

A) Multiple-response questions award partial credit for selecting some correct options
B) Multiple-choice questions always present exactly two answer options
C) Multiple-response questions require selecting more than one correct option from the answer list
D) Multiple-response questions are graded as open-ended written responses

<details>
<summary>Answer</summary>

**Correct: C**

Multiple-response questions explicitly require selecting two or more correct options from the list, unlike multiple-choice questions which have a single correct answer.

**Why the others are wrong:**
- The exam does not award partial credit; multiple-response items require all correct options selected to score the point.
- Multiple-choice questions typically present four options, not a fixed count of two.
- Multiple-response questions are still selected-answer format, not free-text or essay responses.

</details>

**Q6.** A user wants to generate a standalone code snippet or document that can be edited and iterated on separately from the ongoing conversation thread. Which Claude.ai surface is designed for this?

A) Chat
B) Artifacts
C) Projects
D) Research mode

<details>
<summary>Answer</summary>

**Correct: B**

Artifacts creates a separate, editable workspace for generated content like code or documents that can be iterated on outside the main chat flow.

**Why the others are wrong:**
- Chat keeps content embedded in the conversation history rather than as a separate editable object.
- Projects stores shared context and files but is not the feature for isolating a single editable generated output.
- Research mode focuses on multi-source synthesis, not on producing an editable standalone artifact.

</details>

**Q8.** A company needs the fastest, lowest-cost model for high-volume, simple text classification tasks. Which Claude model family should they select?

A) Opus
B) Haiku
C) Sonnet
D) Any family performs identically for this use case

<details>
<summary>Answer</summary>

**Correct: B**

Haiku is the fastest and lowest-cost model family, optimized for high-volume, lightweight tasks like simple classification.

**Why the others are wrong:**
- Opus is the most capable but slowest and most expensive family, overkill for simple classification at scale.
- Sonnet balances cost and capability but is not the cheapest or fastest option for this use case.
- The model families differ significantly in speed and cost, so they are not interchangeable for this scenario.

</details>
