## Chapter 1 Cheat Sheet: Exam Overview & Claude Product Landscape

### Exam Logistics
| Item | Value |
|---|---|
| Total questions | 60 |
| Time limit | 120 minutes |
| Avg. time/question | ~2 min (budget slightly under for review buffer) |
| Scaled score range | 100–1000 |
| Passing threshold | 720 |
| Registration portal | Anthropic Partner Academy |
| Delivery options | Pearson VUE OnVUE (remote online proctoring) OR physical test center |

**Exam note:** Score is *scaled*, not a raw percentage — don't assume 70% correct maps to 700.

### Question Formats
| Format | Description | Key Trap |
|---|---|---|
| Multiple-choice | One correct answer among 4 options | Standard format — most common |
| Multiple-response | Must select ALL correct options (more than one) | No partial credit — missing one option = wrong |

### Claude.ai Surfaces
| Surface | Best For | Not For |
|---|---|---|
| Chat | Single-session conversational Q&A | Persistent cross-session context |
| Projects | Reusable context, shared docs/instructions across sessions | One-off standalone outputs |
| Artifacts | Standalone editable output (code, docs) iterated separately | Multi-source deep research |
| Research mode | Multi-step, multi-source synthesis with citations | Quick single-turn answers |

**Common mistake:** Choosing "Chat" for scenarios describing reusable context or multi-source research — look for Projects or Research mode cues instead.

### Model Family Overview
| Family | Speed/Cost | Best Use Case |
|---|---|---|
| Haiku | Fastest, cheapest | High-volume, simple tasks (classification, short replies) |
| Sonnet | Balanced | General-purpose everyday workloads |
| Opus | Slowest, most expensive | Complex reasoning, highest-capability tasks |

**Exam note:** Scenario questions testing model selection hinge on cost sensitivity + task complexity — match accordingly.

### Pacing Strategy
1. 120 min ÷ 60 questions = 2:00/question average.
2. Target 1:30–1:45/question to build a review buffer.
3. Flag uncertain questions and return at the end.
4. Don't spend more than ~3 min on any single question — move on and flag it.

### Quick Pass/Fail Check
- Score ≥ 720 on 100–1000 scale → **Pass**
- Score < 720 → **Fail** (no partial/borderline review process)
