# Chapter 9 Cheat Sheet: Full Exam Simulation & Scoring Strategy

## Exam Structure
| Item | Value |
|---|---|
| Total questions | 60 |
| Total time | 120 minutes |
| Avg. time/question | ~2 minutes |
| Multiple-response items | Require MORE than 2 min — budget extra |
| Passing score | 720 / 1000 (scaled) |
| Certification validity | 12 months |
| On-time renewal | Free, non-proctored |

## Scaled Score Reality Check
- 720/1000 is **not** 72% of 60 raw questions.
- Scaled scoring adjusts for item difficulty and domain-level performance.
- A candidate can get 75% raw correct and still score below 720 if misses cluster in heavily-weighted or harder-calibrated items.
- **Never** estimate pass/fail using simple raw percentage math.

## Pacing Checkpoints
| Question # | Elapsed Time (on pace) |
|---|---|
| 15 | ~30 min |
| 30 | ~60 min |
| 45 | ~90 min |
| 60 | ~120 min |

If ahead at checkpoint → bank time for flagged review.
If behind at checkpoint → trim time on remaining easy items, don't panic-rush everything.

## Domain Review Priority (example weighting)
| Priority | Domain | Weight |
|---|---|---|
| 1st | Output Evaluation | 21% (heaviest) |
| 2nd+ | Remaining 6 domains | Balance of 79% |

Review flagged questions in descending order of domain weight when time is short — fixing a mistake in the heaviest domain has the greatest scaled-score impact.

## Flag-and-Return Protocol
1. Uncertain question → **Flag**, select best guess, move on.
2. Never dwell past ~2x the average time on one item.
3. After final question, return to flagged list.
4. Review flagged items by domain weight, heaviest first.
5. Only change an answer if you find a concrete, specific reason — not from anxiety alone.

## Multiple-Response Trap
- No partial credit: all correct options required.
- Read every option fully before selecting — don't stop at the first plausible match.
- Budget extra seconds here; rushing causes incomplete selections.

## Post-Exam
- Certification valid 12 months from pass date.
- Renew **before** expiration → free, non-proctored.
- Miss the window → full proctored retake required, at standard cost.
