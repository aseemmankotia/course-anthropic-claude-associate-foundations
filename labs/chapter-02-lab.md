# Chapter 2 Lab: Output Evaluation and Validation

**Estimated time:** 25 minutes

## Exercise

Build a validation checklist for an AI-drafted client email, then apply it line by line to a real Claude output, marking each claim as verified, unverifiable, or flagged for human review

## Key takeaway

Trustworthy output comes from a repeatable verification process, not from how confident or well-written the response sounds.
