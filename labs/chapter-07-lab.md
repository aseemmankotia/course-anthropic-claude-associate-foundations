# Chapter 7 Lab: Configuration and Knowledge Management

**Estimated time:** 20 minutes

## Exercise

Build a Claude Project for a recurring work task (e.g., weekly newsletter drafting), add custom instructions defining tone and structure, upload two knowledge-source documents, and test that outputs reflect both the instructions and the source material

## Key takeaway

A Project's custom instructions and knowledge sources need periodic review — configuration is not a one-time setup.
